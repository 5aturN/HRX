# 04 — Фронтенд и дизайн

React + TypeScript + Vite. Собирается в `frontend/dist`, бэк раздаёт его с того же адреса (требование Mini App).

## Дизайн под Гидробот

- Тёмный фон `#101014`, карточки `#1a1a20`, лаймовый акцент `#dff83a` (как кнопка «Задать вопрос» на gidrobot.ru), фиолет `#5e2bff` вторым.
- Логотип: `frontend/public/logo.png` (с сайта), в шапке и фавиконке.
- Берём цвета из `Telegram.themeParams`, если телега их отдала.
- Главный экран — крупные карточки, внизу — вкладки с иконками. Тактильный отклик через `HapticFeedback`.
- Все стили — в `src/theme.ts` (объект `T` + строка `css`), страницы используют классы `hrx-*`. Новых css-файлов не плодим.

## Страницы (`src/pages/`)

| Страница | Что делает |
|---|---|
| `ReceiptPage` | Шапка поставки + строки деталь/покупнина. |
| `StockPage` | Поиск, русские колонки, подсветка «низко». |
| `AssemblePage` | Изделия, состав, проверка, кнопка собрать. |
| `OrdersPage` | Заказы с прогресс-баром, «просто на склад» сверху. |
| `MovesPage` | Поиск позиции → брак / возврат / выдача в проект. |
| `ReportsPage` | Движения с фильтром по датам + кнопка Excel. |
| `AdminPage` | Заявки, активация, роли, блокировка. |

## Связь с бэком (`src/api/client.ts`)

Один `fetch`: относительный путь `/api/...`, заголовок `X-Telegram-Init-Data` из `Telegram.WebApp.initData`. Задел под сканер: `<ScanButton onScan={...} />` (в будущем `@yudiel/react-qr-scanner`).

Фото: позиции (`POST /api/items/{id}/photo`), аватары (`POST /api/me/avatar`), отдача через `/api/.../photo` и `/api/users/{id}/avatar`. Фронт показывает миниатюры в складе и кабинете, без фото — заглушка. Картинки жмутся до 800px (аватары 256px) через Pillow.
