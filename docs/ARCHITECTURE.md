# Как устроен склад

- Остаток живёт в `items.qty` (общая масса). Поставки — только история приходов.
- Папки: где лежит. Сборки (BOM): из чего состоит. Это разные вещи.
- `bom_items(parent, child, qty, version)` любой глубины, циклы запрещены, версия пишется на сборке.
- Химия в составе — только пометка (`bom_chemistry`), в сборку не списывается. Тюбики считаются отдельно, руками.
- Два журнала: `stock_moves` (движения) и `audit_log` (действия людей).
- Заказ: покупатель + строки (изделие, надо, готово). Сборка без заказа — `order_id = NULL`.
- Пороги: `items.threshold + notify_enabled`, письма закупщикам + копия админу.
- Тесты: `backend/tests`, гоняются `pytest`. 29 штук в 9 файлах (включая закалку: ready ok/503 и антиспам low_notified).
- Фронт: 5 вкладок внизу (Главная, Склад, Сборка, Приёмка, Кабинет), остальное через главную; 12 страниц; тёмная/светлая из Telegram.
