# 07 — Тесты

Бэк: `pytest` (asyncio_mode=auto), фронт: `tsc --noEmit`.

```powershell
cd backend
..\.venv\Scripts\python -m pytest tests -q   # сейчас 16 штук, все зелёные
cd ..\frontend
npx tsc --noEmit
npm run build
```

## Что покрыто

- Приёмка: создание, повтор артикула (без дублей), деталь без децимального — отказ, поиск, документы.
- Сборка: проверка нехватки, подсборка отдельной кнопкой, изделие после, прогресс заказа, кольцо — ошибка.
- Движения: брак без причины — отказ, брак/возврат считают, больше остатка — отказ, выдача в проект, химия.
- Отчёты: движения видны, Excel с листами «Остатки» и «Движения», пользователи и заказы.

## Правила

- Новый роут — новый тест. Красные тесты в `main` не сливаем.
- Фикстуры: каждому тесту свой файл БД, клиент ходит через ASGI. Объекты между сессиями не таскаем — только id.
