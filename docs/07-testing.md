# 07 — Тесты

Бэк: `pytest` (asyncio_mode=auto), фронт: `tsc --noEmit`.

```powershell
cd backend
..\.venv\Scripts\python -m pytest tests -q   # 29 тестов в 9 файлах, все зелёные
cd ..\frontend
npx tsc --noEmit
npm run build
```

## Что покрыто

- Приёмка (5): создание, повтор артикула (без дублей), деталь без децимального — отказ, поиск, документы.
- Сборка (5): проверка нехватки, подсборка отдельной кнопкой, изделие после, прогресс заказа, кольцо — ошибка.
- Движения (4): брак без причины — отказ, брак/возврат считают, больше остатка — отказ, выдача в проект, химия.
- Отчёты (2): движения видны, Excel с листами «Остатки» и «Движения», пользователи и заказы.
- Фото (3): позиция, аватар+кабинет, дерево. Каталог (2): автоподстановка, список. Избранное (1). Безопасность (3): без токена отказ, старое отказ, доки закрыты.
- Закалка (4): ready ok, ready 503 при мёртвой базе, антиспам low_notified (письмо → молчим → пополнение → снова), приёмка в проект флаг не сбрасывает.

## Правила

- Новый роут — новый тест. Красные тесты в `main` не сливаем.
- Фикстуры: каждому тесту свой файл БД, клиент ходит через ASGI. Объекты между сессиями не таскаем — только id.
