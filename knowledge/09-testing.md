# 09 — Тесты и качество

Бэк: pytest, `asyncio_mode=auto`, `testpaths=tests`. Фикстуры (`conftest.py`): DEV=1 через env до импорта app, каждому тесту свой файл БД (tmp_path), клиент — httpx через ASGI (честный async). Правило: объекты между сессиями не таскаем — только id (иначе MissingGreenlet). Новый роут — новый тест. Красные в main не сливаем.
Фронт: `tsc --noEmit`. Сборка — тоже проверка.
