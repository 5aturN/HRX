# 06 — Каталог стандартов

Идея: не вбивать «Винт с цилиндрической головкой» сто раз и не фоткать каждый винт — завести эталон один раз, дальше выбирать код и получать название + фото автоматом. Особенно для метизов (DIN912 vs ISO7380 — разные головки, глазом видно сразу) и химии (LOCTITE243 — банку видно сразу).

## Как работает

```
Админ: Каталог → код DIN912 + название → загрузить фото банки/винта
Кладовщик: Приёмка → в строке вбивает DIN912 → видит фото + название → добавляет размер (М6х20) → Принять
Бэк: находит эталон → имя пустое? берёт из каталога → фото эталона копирует в позицию
Все: в складе/сборке/избранном винт с картинкой, читать не надо
```

Своё фото позиции важнее каталожного. Если своего нет, а код есть — отдаём эталонное (фолбэк). Если позиция уже была без кода, а пришла с кодом — приклеиваем.

## Эталоны в сидах (12)

| Код | Название | Подсказка |
|---|---|---|
| DIN912 | Винт с цилиндрической головкой (внутр. шестигранник) | ходовой под ключ |
| DIN933 | Болт с шестигранной головкой (полная резьба) | ходовой болт |
| DIN934 | Гайка шестигранная | ходовая |
| DIN125 | Шайба плоская | — |
| DIN127 | Шайба пружинная (гровер) | от самоотвинчивания |
| ISO7380 | Винт с полукруглой головкой | на видные места |
| ISO4762 | Винт с цилиндрической (аналог DIN912) | то же |
| DIN7991 | Винт с потайной головкой | впотай |
| DIN965 | Винт с потайной (крест) | впотай |
| DIN7981 | Саморез с полукруглой головкой | по металлу |
| GOST14771 | Электрод сварочный | сварка |
| LOCTITE243 | Фиксатор резьбы средний (синий) | капля на резьбу |

Фото в сидах нет (только названия) — залейте руками через страницу «Стандарты» с телефона. Файл: `backend/seed_catalog.py`.

## API каталога

GET /api/catalog — все (код, название, описание, has_photo). POST /api/catalog (admin) — создать/обновить (код в верхний регистр). POST /api/catalog/{code}/photo (admin) — фото (JPG 800). GET /api/catalog/{code}/photo — отдать. Файлы: `routers/catalog.py`, модели `StdCatalog`, страница `CatalogPage.tsx`, выбор `StdPicker.tsx`.

## Химия и каталог

LOCTITE243 заведён как эталон. В составе (`bom_chemistry`) химия показывает фото банки из каталога — сборщик видит что мазать. Списание тюбиков — руками через chem-out (см. главу 01). Порог по штукам.
Хотелка из обсуждения: «при выборе клея в сборке появлялась моделька банки» — сделано через фото эталона. 3D-моделек нет и не надо.
