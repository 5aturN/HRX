# Склад Гидробот — полная техдокументация

Telegram Mini App для склада производственного предприятия. Один репозиторий, один адрес: бэк на FastAPI раздаёт собранный фронт.

![Логотип](img/logo.png)

Репозиторий: https://github.com/5aturN/HRX. Ветка `main` — прод. Работа — в `feature/*`, слияние через `--no-ff`.

## Глоссарий

| Слово | Что значит у нас |
|---|---|
| Позиция | любая строка справочника: деталь, покупнина, подсборка, изделие |
| Деталь | наше, изготавливаемое. Децимальный номер обязателен |
| Покупнина (стандарт) | покупное без переделки: винт, гайка, клей. Децимального нет, есть код каталога |
| Подсборка | собирается из деталей и стандартов, лежит на складе как штука |
| Изделие | верхнее: манипулятор, захват. Тоже собирается |
| Папка | где лежит. Дерево: Склад → Серийная / Расходники / R&D |
| Состав (BOM) | из чего состоит: подсборка или изделие → дети с количествами |
| Химия-пометка | клей/обезжириватель в составе без количества, в сборку не списывается |
| Партия (поставка) | один приход: шапка + строки. История, остаток живёт отдельно |
| Общая масса | остаток позиции — одно число, без разбивки по партиям |
| Умная сборка (вариант Б) | проверка показывает чего нет и что дособрать, сама молча ничего не собирает |
| Теневой заказ | сборка без заказа (`order_id = NULL`), пункт «Просто на склад» |
| Порог | неснижаемый остаток. Упали ниже — пишем закупщикам |
| Каталог | эталоны DIN/ISO/ГОСТ: код → название + одно фото на всех |
| Избранное | звёздочки, у каждого пользователя свои |
| UPT/УПД | универсальный передаточный документ, фото/ PDF к поставке |
| initData | подпись Телеги, по ней понимаем кто стучится |

## Как читать

- Хочешь понять зачем — глава 01.
- Хочешь понять как устроено — 02, потом 03–05.
- Настраиваешь сервер — 08.
- Допиливаешь код — 03–05 + 09.
- Споришь что делать дальше — 10.

Доки лежат рядом с кодом и обновляются вместе с ним. Нашёл враньё — поправь тут же.
