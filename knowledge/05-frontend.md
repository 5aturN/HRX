# 05 — Фронтенд

React 18 + TS + Vite 6. Сборка в `dist` (бэк раздаёт). `tsc --noEmit` чистый, `noEmit: true` (чтобы tsc не сыпал .js). Проверка типов — `npx tsc --noEmit`, сборка — `npm.cmd run build` (именно npm.cmd: обычный npm режется политикой Windows, см. главу 08).
`index.html`: viewport-fit=cover (чёлка!), theme-color, telegram-web-app.js, заголовок «Склад Гидробот», фавиконка — логотип. `main.tsx`: mount App.

## Дизайн: глубокий синий + лайм

Референс — банковское мини-приложение с тёмными скруглёнными экранами (фото в задаче). Наш акцент — лайм Гидробота `#dff83a` (кнопка «Задать вопрос» на gidrobot.ru), фон — глубокий синий `#1a1a2e`, карточки `#23233f`. Логотип (`public/logo.png`, 6.9 КБ с сайта) — в шапке, на главной (88px), в фавиконке.
Тёмная/светлая берётся из `Telegram.themeParams` + `colorScheme` (функция `tgColors`): тёмная — наши синие, светлая — белые iOS-карточки. Все стили — один файл `src/theme.ts` (объект T + функция + массив C → строка css), страницы используют классы `hrx-*`, новых css-файлов нет.
Чёлка: `env(safe-area-inset-*)` в шапке (sticky + blur), вкладках (fixed), тостах. Плюс `setHeaderColor/setBackgroundColor/disableVerticalSwipes` при старте. Низ — отступ 120px чтобы вкладки не перекрывали. Скелетоны (pulse), тосты (лайм/красный, 2.2с), тактильный отклик (HapticFeedback light/success/error).

## Навигация (`App.tsx`)

Вкладки внизу (5): Главная (H), Склад (W), Сборка (A), Приёмка (+), Кабинет (U). Активная — лаймовая. Остальные экраны (заказы, движения, отчёты, стандарты, избранное, остатки) — через главную. `go()` — вибрация + скролл вверх. `toast(msg, ok)` — глобальный, элемент `#hrx-toast`. Стили вшиваются тегом `#hrx-style`.

## Связь с бэком (`api/client.ts`)

Один `api(path, initData, body, retry)`: initData из `Telegram.WebApp.initData`, POST если body есть. Ошибки русским: 401 «Откройте через Telegram», 403 «Нет прав», 429 «Подождите минуту», остальное — текст (200 символов). Обрыв сети — повтор через 800мс. Фото — FormData с тем же заголовком (fetch напрямую). Excel — `window.open` с `?init=` (токен в URL — неидеально, см. главу 07).

## Страницы (12)

`HomePage`: баланс-карточка (привет + всего штук + позиции/ниже порога + 3 быстрые кнопки Принять/Собрать/Найти), кабинет-карточка (аватар/инициал, имя, должность → тап в кабинет), «Срочно заказать» (4 ниже порога), «Сегодня делали» (5 последних), разделы Склад (Склад, Избранное, Заказы, Стандарты) и Ещё (Брак, Отчёты, Люди) с цветными иконками.
`WarehousePage`: поиск + дерево папок (Node рекурсивно, раскрытие, счётчики позиций/штук, миниатюры 50px, звёздочки FavStar). Поиск — до 20 с папкой и остатком.
`ReceiptPage`: шапка (поставщик, УПД, счёт) + строки (тип, StdPicker для покупнин, артикул-размер, название с подсказкой «подставится», децимальный для деталей, кол-во). Отправка: шапка+строки одним POST, имя пустое → null → бэк подставит.
`AssemblePage`: изделия с фото → состав с фото и ✓/! → химия с фото банки → «Дособрать» кнопки → кол-во + Проверить + Собрать. Сообщения русским.
`OrdersPage`: «Просто на склад» сверху, карточки (покупатель, русский статус, прогресс-бар, строки) + кнопки статуса + собрать в заказ (переход в сборку; order_id пока не пробрасывается — см. главу 10!). Новы покупатель — поле + плюс.
`MovesPage`: поиск с фото + галочка выбора → кол-во + причина + проект → три кнопки (брак красная, возврат, выдача). Блокировка пока отправляется, тосты, вибрация.
`ReportsPage`: даты от/до → Показать/Excel → лента движений (тип, дата, sku, кол-во, до 60). `StockPage`: старый поиск-таблица (остался, используется в тестах? нет — живой экран, но дублирует склад; кандидат на удаление). `CatalogPage`: список эталонов с фото + загрузка фото (label+hidden input) + новый код. `FavsPage`: моё избранное с фото и звёздами. `ProfilePage`: большой аватар/инициал, имя, должность, роли/статус/неделя, смена фото. `AdminPage`: ждут (с выбором роли worker/purchaser/admin) + активные + блок.

## Компоненты (2)

`StdPicker(value, onPick)`: поле кода + фото текущего + выпадашка из 8 совпадений (код/название, с фото). Каталог грузит раз при старте. `FavStar(itemId, init)`: звезда ★/☆, тумблер с stopPropagation.

## Что не так (честно)

- StockPage дублирует WarehousePage — удалить или свернуть.
- OrdersPage → AssemblePage не передаёт order_id (сборка всегда «на склад») — пробросить.
- Excel через ?init= в URL — токен в истории браузера; лучше скачивать blob через fetch.
- StdPicker без debounce — каждый ввод фильтрует локально (ок при 12 позициях, при 500 надо debounce + серверный поиск).
- Нет обработки offline — чёрный экран при обрыве (только повтор в api).
- Иконки вкладок — буквы (H/W/A/+), лучше SVG.
